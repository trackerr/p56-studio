# P56 POV Display

Holoscope / P56 POV fans in Home Assistant, without the vendor app or cloud.

- Sidebar panel with the full P56 Studio web app
- The `p56_pov` integration is discovered automatically
- Messages with priorities: text, icons, prices, camera snapshots, GIFs and videos
- AI pictures, made by ComfyUI on a computer in your house or by an AI in Home Assistant
- HTTP API for text and pictures (`/api/show`), compatible with add-on 1.x

See the **Documentation** tab.
